About Me

This website was created as part of a CSS styling assignment. The goal is to practice styling existing HTML pages with a single external CSS file.

Project Objectives

The project uses CSS selectors, properties, and values to modify fonts, background colors, text alignment, line spacing, and element dimensions.

Accessibility is also important. Color contrast should be checked using the WAVE Web Accessibility Evaluation Tool.
